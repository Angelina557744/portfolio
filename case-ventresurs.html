VentResurs

Веб-приложение для инжиниринговой компании: сайт с каталогом услуг, личные кабинеты для клиентов, админ-панель для сотрудников, чат по проектам и модуль искусственного интеллекта для обработки обращений.

Задача

У компании не было единого цифрового канала для работы с клиентами. Заявки приходили по телефону и почте, учитывались в таблицах, часть обращений терялась при передаче между сотрудниками. Клиенты не могли отследить статус своих проектов, а руководство не видело объективной картины по загрузке менеджеров.

Нужно было собрать сайт, который закроет весь цикл: от первого обращения и предварительного расчёта стоимости до личного кабинета, чата по проекту и внутренней админ-панели для сотрудников.

Что реализовано

Публичная часть сайта

Главная, каталог услуг, портфолио реализованных объектов, страница контактов с интерактивной картой. Всё адаптивно, с единым дизайном и быстрой загрузкой. Изображения оптимизированы, иконки подключены через Lucide Icons.

Регистрация и авторизация

Клиенты создают учётные записи, пароли хешируются через bcrypt. После входа открывается сессия и доступ к закрытым разделам. Формы проверяются и на клиенте, и на сервере.

Личный кабинет клиента

История расчётов, текущие заявки, статусы проектов, ответы от менеджеров и чат по каждому проекту. Клиент в любой момент видит, на каком этапе находится его заказ, и может задать вопрос напрямую сотруднику.

Инженерный калькулятор

Пошаговый расчёт предварительной стоимости монтажа систем вентиляции. Клиент отвечает на вопросы, система считает стоимость по формуле с коэффициентами и формирует коммерческое предложение. Результат сохраняется в истории личного кабинета.

Интеграция с GigaChat

Входящие обращения автоматически классифицируются нейросетью по темам, а в калькуляторе GigaChat формирует персональные технические рекомендации по подобранному оборудованию. Это снимает часть рутины с менеджеров и ускоряет первичную обработку заявок.

Админ-панель

Отдельный интерфейс для сотрудников. Менеджеры обрабатывают заявки, меняют статусы проектов, отвечают клиентам в чате. Администратор управляет контентом сайта, редактирует услуги, портфолио и изображения без правки кода. Права разграничены по ролям.

Чат между клиентом и сотрудником

Внутри личного кабинета и админ-панели работает чат по каждому проекту. Сообщения сохраняются в базе, клиент получает уведомления об ответах, история переписки остаётся доступной в любой момент.

Роли и права доступа

В системе три роли: клиент, менеджер, администратор. Каждая видит только свои разделы и может выполнять только разрешённые действия. Данные защищены от несанкционированного просмотра и редактирования.
